# Chef Home 🍳

A collaborative recipe platform that bridges the gap between professional chefs and home cooks, enabling a community-driven culinary experience.

## 🚀 Overview
Chef Home is a comprehensive frontend recipe platform designed to bridge the gap between professional chefs and home cooks. It features a sophisticated state management system that mimics backend functionality, allowing users to create, edit, and curate recipes locally with a seamless user experience.

## 🛠 Tech Stack
* **Frontend:** React.js
* **State Management:** Redux Toolkit
* **Routing:** React Router
* **Styling:** Tailwind CSS
* **Data Fetching:** Axios
* **Persistence:** Browser Local Storage
* **Deployment:** Vercel

## ✨ Key Features
* **Recipe Management (CRUD):** Empowering users to create, read, update, and delete their own recipes.
* **Community Favorites:** Personalized "Favorite" system allowing users to curate and save recipes for quick access.
* **User Authentication:** Secure access for chefs and home makers to manage their personal recipe portfolio.
* **State Persistence:** Integrated `localStorage` ensures that user-created recipes and favorites remain saved across sessions.
* **Responsive Design:** A mobile-first, clean interface built with Tailwind CSS to ensure recipes look great on any device.
